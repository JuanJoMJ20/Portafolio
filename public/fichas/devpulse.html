DevPulse

Dashboard de productividad y bienestar para programadores que detecta la fatiga mental mientras trabajas y simplifica la pantalla antes de que el cansancio te gane.

IA entrenada en tu equipo Retícula adaptativa 4 → 2 columnas Modo claro y oscuro · WCAG AA 100% datos locales
01

Qué es

Los dashboards de productividad muestran siempre la misma cantidad de información, estés fresco o agotado, y la fatiga se nota cuando ya es tarde. DevPulse es una app de escritorio para Windows que invierte ese orden: mide tu actividad real y adapta la interfaz a tu carga mental.

Antes

Llevas horas sin pausa → saltas entre Slack, el navegador y el editor → la pantalla sigue llena de métricas → te das cuenta del cansancio cuando ya cometes errores.

→

DevPulse

Detecta la fatiga por tu actividad → al pasar de 70/100 oculta lo secundario y deja solo temporizador y notas → cierra las apps que distraen.

02

Para qué sirve

∿

Carga mental en vivo

Un índice de 0 a 100 cada 2 segundos, calculado con 4 señales reales: saltos entre apps, tiempo sin pausa, correcciones al teclear y ritmo de tecleo.

✦

IA que aprende de ti

Cada 25 minutos pregunta "¿cómo te sientes?" (1 a 5) y reentrena un modelo propio. Muestra qué ha aprendido: el peso de cada señal y cuánto bajó el error.

▦

Interfaz adaptativa

Vista densa de 4 columnas, equilibrada de 3 o "Enfoque Absoluto" de 2, según la carga. Se puede fijar a mano en cualquier momento.

⛨

Bloqueador de contexto

Cierra Slack, Discord, WhatsApp o cualquier programa que añadas. Primero les pide cerrarse para que guarden lo pendiente; si siguen abiertos, los fuerza.

◷

Pomodoro y mapa de calor

Temporizador con tareas divididas en pasos y cola de pendientes. Cada minuto de enfoque alimenta un mapa de 7 días × 24 horas que muestra cuándo rindes mejor.

⌂

Cuentas, ajustes y tutorial

Cuentas locales con datos y modelo propios, ajustes de tema y duraciones, y un tutorial guiado que ilumina cada sección y explica para qué sirve.

◐

Accesible en los dos temas

Modo claro y oscuro con contraste AA, uso completo con teclado, botón "Deshacer" en acciones destructivas y respeto a "reducir movimiento" del sistema.

!

Errores humanizados

Todo aviso del sistema explica qué pasó, por qué, y qué hacer ahora — nunca un código de error crudo.

03

Parte técnica

Plataforma
App de escritorio para Windows con Electron 45, empaquetada con electron-builder en un instalador NSIS (DevPulse.exe)
Interfaz
React 19 + TypeScript 5.8, compilado con Vite 6
Diseño
Tailwind CSS 4 con tokens de color semánticos que cambian por tema; el cambio de retícula se anima con la View Transitions API (sin librerías de animación)
Señales del PC
koffi lee la ventana activa con la API de Windows · uiohook-napi mide el ritmo de tecleo · powerMonitor de Electron detecta la inactividad
IA
Regresión logística propia en JavaScript, entrenada en el equipo por descenso de gradiente (1.500 iteraciones, ~100 ms) — sin servicios externos ni librerías de ML
Cuentas
Locales: contraseña con hash scrypt + sal y comparación en tiempo constante; un archivo de datos por cuenta
Persistencia
JSON en %APPDATA%\DevPulse con escritura atómica (archivo temporal + renombrado), para no corromper datos si la app se cierra a mitad de guardar
Accesibilidad
WCAG 2.1 AA verificado con un script: 120 combinaciones de texto y fondo en los dos temas, mínimo 4,70:1 (la norma pide 4,5:1)
// modelo personal de fatiga
p(fatiga) = σ(b + w₁·saltos + w₂·sin_pausa + w₃·correcciones + w₄·ritmo)
// regularización L2 hacia los pesos iniciales, fuerza = 0,3 / (n + 2)

Regresión logística, no una red neuronal

Cada usuario aporta pocas decenas de respuestas y hace falta explicar la predicción. Con 4 entradas, una red neuronal sobreajustaría y sería una caja negra; la logística da pesos que se pueden mostrar en pantalla. En una prueba con 20 respuestas, el error medio bajó de 21 a 11 puntos.

Umbrales con histéresis para que la pantalla no parpadee

La interfaz entra en Enfoque Absoluto al pasar de 70, pero no vuelve hasta bajar de 58. Con un solo umbral, una carga que ronda el límite haría saltar la retícula cada 2 segundos.

La barra superior se movía con cada cambio de carga

Detectado usando la app: el subtítulo cambiaba de largo con cada vista y empujaba los controles. Se resolvió con una retícula de 3 columnas fijas y anchos fijos para cada número, verificado midiendo las posiciones en todos los estados.

El contraste se midió, no se eligió a ojo

Al añadir el modo claro, el script de contraste encontró 7 combinaciones por debajo de 4,5:1, sobre todo textos naranjas sobre fondos tintados. Se oscurecieron esos tokens y se añadió uno específico para bordes de controles (≥ 3:1).

Del teclado solo se guarda cuándo, nunca qué

El gancho global de teclado registra la hora de cada pulsación y si fue Retroceso o Suprimir. Con eso basta para medir ritmo y correcciones sin capturar nada de lo que se escribe.

●

Privacidad por diseño: todo se calcula y se guarda en el equipo del usuario; DevPulse no envía nada a ningún servidor ni a ninguna API externa. Sin sesión iniciada no se mide nada. El índice de carga es una estimación para adaptar la interfaz, no un diagnóstico médico.
